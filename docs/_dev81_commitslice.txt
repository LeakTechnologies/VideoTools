dev81: release v0.1.1-dev81 — rip a title by chapter range (IFO program map + executor + UI)

Rip a title by chapter range, so a user can rip just a specific scene ("rip a
title by chapters, so we could rip just a specific scene if we need to").

The Rip enrichment panel gains a per-rip "Rip chapters only" toggle plus From/To
chapter selects. Bounds = the greatest chapter count across ALL scanned titles, so
the range never invalidates when the picked title changes; each title clamps the
range at execute. Toggle + selects are inert for full-disc rip, region conversion,
and the archivist format, and the selection is a per-rip transient that is never
persisted to config.

- dvdvideo path trims with output-side -ss/-to (appended after all inputs; the
  timeline normalises to 0, no chapter 1 content).
- VOB-concat fallback slices each VOB to exactly the cells serving the selected
  programs via new TitleInfo.ProgramEntryCells (PGC program-map entry cells,
  retained in the same PGC pass that reads chapters). Span = [entry(cs)-1,
  entry(ce+1)-1); whole-cover short-circuit skipped while a range is active; an
  unresolvable range degrades to whole-file concat + -ss/-to.
- Embedded chapters remap to the range base; progress tracks the range span (not
  the whole title); stale-PTS failover cap = range + 5 s when the cell list is
  engaged.

Unit tests cover the chapter remap, the chapter-to-cell span (shared entry cells,
out-of-range rejects, whole-title equivalence), and ranged cell-concat slicing.
Build + vet + tests green. Version triad bumped to v0.1.1-dev81 (Build 71);
six docs synced. Feature doc + tester checklist: docs/RIP_CHAPTER_RANGE.md.
