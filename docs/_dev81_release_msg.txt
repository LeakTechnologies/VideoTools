dev81: release v0.1.1-dev81 (rip a title by chapter range — IFO program map + executor + UI)

Rip a title by chapters, so a user can rip just a specific scene. The Rip enrichment
panel gains a "Rip chapters only" toggle plus From/To chapter selects. The selects'
upper bound is the greatest chapter count across ALL scanned titles (so the widget
never invalidates when the picked title changes); each title clamps the range at
execute; whole-cover short-circuit is skipped while a range is active; a
cells-unresolvable range degrades to whole-file concat + output-side -ss/-to; the
stale-PTS failover cap becomes range duration + 5 s.

- dvdvideo path trims with output-side -ss/-to (appended after all inputs, so the
  timeline normalises to 0 and no option binds to a wrong input).
- VOB-concat fallback slices each VOB to the range's cell span
  [entry(cs)-1, entry(ce+1)-1) using the PGC program map now retained
  (TitleInfo.ProgramEntryCells, filled in the same PGC pass that reads chapters).
- Embedded chapters remap to the range base; progress tracks the range span;
  readiness/readability reflect the range; stale-PTS failover cap = range + 5 s.

Controls are inert for full-disc rip / region conversion / archivist format; the
selection is per-rip transient, never persisted to config. Test coverage:
executor_range_test.go (range validation, chapter remap, whole-title equivalence)
+ cellconcat_test.go (chapter-to-cell span, ranged cell-concat slicing).
